# ExamFlow AI

Telegram-бот для структурированной подготовки к ЕГЭ/ОГЭ с ИИ-репетитором и системой геймификации.

## О проекте

ExamFlow AI решает три главных барьера при подготовке к экзаменам:

- **Структурный** — 5 готовых курсов (86 уроков) с пошаговой навигацией по темам
- **Понятийный** — ИИ объясняет сложные моменты прямо в чате, когда это нужно
- **Мотивационный** — серии дней, достижения и напоминания удерживают дисциплину

ИИ не создаёт курс — он усиливает прохождение готового материала: объясняет темы, генерирует задачи, проверяет ответы.

## Возможности

### Курсы и навигация
- 5 курсов: Математика (базовый и профильный ЕГЭ), Русский язык ЕГЭ, Информатика ЕГЭ/ОГЭ
- Карта курса с прогрессом (✅ пройдено / ▶️ доступно / 🔒 заблокировано)
- Кнопка «↩ К модулю» в каждом уроке — возврат к списку без /start
- Кнопка «▶️ Продолжить» в главном меню — быстрый возврат к текущему уроку

### ИИ-репетитор
- **«❓ Не понял»** — упрощённое объяснение темы с примерами
- **«📝 Хочу практику»** — 5 задач по теме с подсказками и разбором ошибок
- **Проверка ответов** — LLM оценивает ответ и даёт комментарий
- **Подсказка** — одна подсказка на задачу, кнопка исчезает после использования
- Тайм-аут 15 секунд: при зависании Groq бот отвечает fallback-сообщением

### Геймификация
- **Серия дней (Streak)** — растёт при ежедневном выполнении нормы (1 урок + 5 задач)
- **Заморозка** — защищает серию от сгорания на один день
- **7 достижений** — за постоянство, количество задач, длину серии и др.
- **Уведомления** — в 19:00 бот проверяет серии и напоминает не потерять прогресс

### Личный кабинет (`/profile`)
- Серия дней, заморозка, текущий урок
- Прогресс за сегодня (уроков / задач)
- Готовность к экзамену в процентах
- Слабые темы по статистике ответов
- Достижения и детальный прогресс по курсам/модулям

### Команды

| Команда | Описание |
|---|---|
| `/start` | Главное меню, выбор курса |
| `/continue` | Продолжить с последнего урока |
| `/quiz` | Быстрая практика по случайной теме курса |
| `/profile` | Личный кабинет |
| `/stats` | Статистика ответов на задачи |
| `/reset` | Сбросить прогресс текущего курса |
| `/help` | Справка |

## Стек

| Компонент | Технология |
|---|---|
| Bot Framework | aiogram 3.x (async, FSM) |
| LLM | Groq API — Llama 3.3 70B |
| База данных | SQLite (dev) / PostgreSQL (prod), SQLAlchemy async ORM |
| Планировщик | APScheduler — ежедневные уведомления в 19:00 |

## Установка и запуск

```bash
# Клонировать репозиторий
git clone <repo-url>
cd ExamFlow-AI

# Установить зависимости
pip install -r requirements.txt

# Создать .env и заполнить переменные
cp .env.example .env

# Запустить бота
python bot/main.py
```

## Переменные окружения

| Переменная | Обязательная | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ | Токен бота от @BotFather |
| `GROQ_API_KEY` | — | API-ключ Groq. Без него используется MockLLMService (заглушка) |
| `DATABASE_URL` | — | По умолчанию `sqlite+aiosqlite:///examflow.db`. Для PostgreSQL: `postgresql+asyncpg://user:pass@host/db` |
| `LLM_TIMEOUT` | — | Тайм-аут запросов к LLM в секундах. По умолчанию `15` |

## Формат courses.json

Все курсы хранятся в `bot/data/courses.json`. При старте бота `CourseService` автоматически валидирует файл — при ошибке бот не запустится и покажет точный путь к проблеме.

Минимальная структура одного урока:

```json
{
  "courses": [
    {
      "course_id": "my_course",
      "title": "Название курса",
      "description": "Краткое описание",
      "modules": [
        {
          "module_id": "mod_01",
          "title": "Название модуля",
          "lessons": [
            {
              "lesson_id": "lesson_01",
              "title": "Название урока",
              "content": "Текст теории (минимум 50 символов)...",
              "summary": "Главное за 1 минуту — краткий вывод.",
              "tags": ["тег1", "тег2"]
            }
          ]
        }
      ]
    }
  ]
}
```

Обязательные поля урока: `lesson_id`, `title`, `content`, `summary`. Все `lesson_id` должны быть уникальны по всему файлу.

## Known Issues

- **MockLLMService** — без `GROQ_API_KEY` бот работает с заглушкой: объяснения и задачи захардкожены. Для полноценной работы нужен реальный ключ.
- **SQLite и конкурентность** — при высокой нагрузке рекомендуется переключиться на PostgreSQL через `DATABASE_URL`.
